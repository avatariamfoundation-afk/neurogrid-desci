# NeuroGrid DeSci

This repository implements the decentralized science (DeSci) layer of NeuroGrid.

## Capabilities
- Research registration & indexing
- Ethics and scope enforcement
- Proposal governance
- Funding intent signaling

## Explicit Boundaries
This system does NOT:
- Diagnose patients
- Process real medical data
- Execute financial transfers

## Architecture
CORE → MEDINTEL → DESCI

All DeSci actions are auditable, reversible, and non-clinical.

## Status
Functional MVP with tests and CI-ready structure.

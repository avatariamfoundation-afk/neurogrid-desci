## NeuroGrid – DeSci Layer

Silent Root Repository

---

## Executive Summary
The NeuroGrid DeSci Layer is a non-executing, governance-centric repository that defines how decentralized science, medical research coordination, and ethical oversight integrate with the NeuroGrid protocol.
This repository is intentionally silent:

No smart contracts
No runtime execution
No clinical logic
No AI models

Its role is to provide:
Research governance primitives
Ethical and compliance scaffolding
Provenance and funding logic design
DAO-aligned scientific coordination

This design ensures regulatory safety, auditability, and future scalability without contaminating the on-chain core with mutable or jurisdiction-sensitive logic.

---

## What This Repository Is (and Is Not)
### DeSci Layer IS
A governance and research coordination framework
A design-level system of record for decentralized science
A provenance and ethics reference layer
A policy and funding logic blueprint

### DeSci Layer IS NOT
A smart contract system
A compute execution layer
A medical system
A data storage or patient data handler
The DeSci layer exists to define rules, not enforce execution.

## Why This Repository Is “Silent”
The DeSci layer is deliberately non-executing for the following reasons:

### 1.Regulatory Safety
Research governance and ethics differ by jurisdiction and evolve over time.

### 2. Audit Clarity
Keeping governance logic off-chain prevents hidden execution paths.

### 3. Upgrade Flexibility
Policy evolution does not require protocol redeployment.

### 4. Separation of Concerns
Execution enforcement belongs to neurogrid-core;
research rules belong here.

This separation is a design choice, not an omission.

## Relationship to On-Chain Enforcement
The DeSci layer does not enforce rules.

Instead:
Rules defined here are referenced by governance
Enforcement occurs in NeuroGrid-Core
Violations trigger on-chain fault codes and slashing

This ensures:
Deterministic execution
Transparent accountability
Clear audit boundaries
